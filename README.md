# Python Apps Collection

This folder contains a small collection of beginner-friendly Python applications.

## Projects

### Calculator
- A simple arithmetic calculator that accepts two numbers and an operator.
- Run it from the Calculator folder with `python main.py`.

### Expense Tracker
- A console-based expense manager that allows adding, viewing, editing, deleting, summarizing, and searching expenses.
- Run it from the Expense_Tracker folder with `python main.py`.

### Weather App
- A weather application that fetches data from the OpenWeather API for a user-provided city.
- Run it from the Weather_App folder with `python main.py` after installing dependencies from `requirements.txt`.

### InterviewBot
- A browser-based voice interview practice app using OpenAI GPT-Live over WebRTC, with natural turn-taking and interruption support.
- Run it from the InterviewBot folder after configuring `OPENAI_API_KEY`; see its README for setup.

### Tutorial Generator
- A browser-based research agent that creates beginner-friendly, sourced PDF tutorials with a visual flow diagram and examples when helpful.
- Run it from the Tutorial_Generator folder after configuring `OPENAI_API_KEY`; see its README for setup.

### InterviewPrep
- A browser-based interview question bank: collects real interview questions from the web (never AI-written) for each technology on the resume, with AI answers pitched at the selected experience level, semantic search (LangChain + Chroma), practice scoring, and PDF/DOCX/HTML export after review.
- Run it from the InterviewPrep folder with `python -m app` after configuring an AI key; see its README for setup.

## Getting Started
1. Open the project folder you want to use.
2. Install any required dependencies if needed.
3. Run the corresponding `main.py` file.
